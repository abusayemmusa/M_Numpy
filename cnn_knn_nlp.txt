1. KNN BASICS
--------------------------------------------------------
KNN = K-Nearest Neighbors

Type:
    Supervised Learning

Main Tasks:
    1. Classification
    2. Regression

Basic Idea:
    কাছের Kটি data point দেখে নতুন point-এর class/value
    নির্ধারণ করা।

Example:
    K = 3

    New Point
       ↓
    Find 3 nearest points
       ↓
    Majority Vote
       ↓
    Predicted Class


========================================================
2. IMPORTANT TERMS
========================================================

K
    Number of neighbors

Neighbor
    কাছাকাছি data point

Distance
    দুই data point-এর দূরত্ব

Feature
    Input variable

Target
    Output variable

Majority Vote
    Classification-এ সবচেয়ে বেশি class নির্বাচন

Average
    Regression-এ nearest neighbors-এর average value

========================================================
4. DISTANCE METHODS
========================================================

1. Euclidean Distance

d = sqrt(
        (x1-y1)^2 +
        (x2-y2)^2 +
        ...
      )

Python:
    from sklearn.metrics import euclidean_distances


2. Manhattan Distance

d = |x1-y1| + |x2-y2| + ...


3. Minkowski Distance

d = (Σ |xi-yi|^p)^(1/p)


4. Chebyshev Distance

d = max(|xi-yi|)


5. Hamming Distance

Used mainly for categorical/binary data.

========================================================
7. WEIGHTED KNN
========================================================

Normal KNN:
    Every neighbor has equal importance.

Weighted KNN:
    Closer neighbors get higher importance.

Common idea:

    Weight = 1 / distance


Example:

Nearest:
    A → very close
    B → far

A gets more influence than B.


========================================================
8. CHOOSING K
========================================================

Small K:
    More sensitive to noise
    Low bias
    High variance

Large K:
    Less sensitive to noise
    Higher bias
    Lower variance


Common starting values:

    K = 3
    K = 5
    K = 7
    K = 9


Best K:
    Choose using validation / cross-validation.


========================================================
9. EVEN vs ODD K
========================================================

Binary classification:

Prefer odd K

Example:
    K = 3
    K = 5
    K = 7

Why?

    Reduce tie possibility.


========================================================
10. FEATURE SCALING
========================================================

VERY IMPORTANT FOR KNN.

Example:

Age:
    20–60

Salary:
    20,000–500,000

Without scaling:
    Salary may dominate distance.


Methods:

1. StandardScaler

2. MinMaxScaler

3. RobustScaler


Python:

from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()

X_train = scaler.fit_transform(X_train)
X_test = scaler.transform(X_test)

22. KNN ADVANTAGES

Advantages:

1. Simple
2. Easy to understand
3. Easy to implement
4. No complicated training process
5. Works for classification
6. Works for regression
7. Can model nonlinear decision boundaries
8. Useful for small datasets


========================================================
23. KNN DISADVANTAGES
========================================================

Disadvantages:

1. Prediction can be slow
2. Large datasets can be expensive
3. Sensitive to feature scaling
4. Sensitive to irrelevant features
5. Sensitive to noisy data
6. Choosing K is important
7. High-dimensional data causes problems
8. Requires storing training data


========================================================
24. KNN COMPLEXITY
========================================================

Training:

Usually very cheap.

Prediction:

Can be expensive because distances
must be calculated.

Memory:

Needs to retain training examples.

25. KNN AND HIGH DIMENSIONAL DATA
========================================================

Problem:

    Curse of Dimensionality

As number of features increases:

    Distance becomes less informative.

Solutions:

    Feature Selection
    PCA
    Dimensionality Reduction
    Remove irrelevant features
