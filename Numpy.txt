29. MODEL CLASS
============================================================

class MyModel(nn.Module):

    def __init__(self):
        super().__init__()

        self.layer1 = nn.Linear(10, 64)
        self.layer2 = nn.Linear(64, 32)
        self.layer3 = nn.Linear(32, 1)

    def forward(self, x):

        x = self.layer1(x)
        x = torch.relu(x)
        x = self.layer2(x)
        x = torch.relu(x)
        x = self.layer3(x)

        return x

class MyDataset(Dataset):

    def __init__(self, X, y):
        self.X = X
        self.y = y

    def __len__(self):
        return len(self.X)

    def __getitem__(self, index):
        return self.X[index], self.y[index]

16. DISCRETE PROBABILITY DISTRIBUTIONS
========================================================

16.1 Bernoulli Distribution
--------------------------------------------------------
Parameters:
    p = probability of success
    q = 1-p

PMF:
    P(X=x) = pˣ(1-p)¹⁻ˣ

x = 0,1

Mean:
    E[X] = p

Variance:
    Var(X) = p(1-p)


16.2 Binomial Distribution
--------------------------------------------------------
Parameters:
    n = number of trials
    p = success probability

PMF:

    P(X=k)
    = C(n,k)pᵏ(1-p)ⁿ⁻ᵏ

Mean:
    np

Variance:
    np(1-p)


16.3 Geometric Distribution
--------------------------------------------------------
PMF:

    P(X=k) = (1-p)ᵏ⁻¹p

Mean:
    1/p

Variance:
    (1-p)/p²

Property:
    Memoryless


16.4 Negative Binomial Distribution
--------------------------------------------------------
Used for:
    Number of trials required
    to obtain r successes.


16.5 Hypergeometric Distribution
--------------------------------------------------------
Used for:
    Sampling WITHOUT replacement.

PMF:

    P(X=k)
    = C(K,k)C(N-K,n-k)
      -------------------
           C(N,n)


16.6 Poisson Distribution
--------------------------------------------------------
Parameter:
    λ

PMF:

    P(X=k) = e⁻λ λᵏ/k!

Mean:
    λ

Variance:
    λ

Use:
    Count of events in a fixed interval.


16.7 Discrete Uniform Distribution
--------------------------------------------------------

16.8 Multinomial Distribution
--------------------------------------------------------
Extension of binomial
for more than two categories.
