3. MATHEMATICAL FOUNDATION
------------------------------------------------------------
Markov Property
Markov Decision Process (MDP)

MDP = (S, A, P, R, γ)

S = State Space
A = Action Space
P = Transition Probability
R = Reward
γ = Discount Factor

Policy:
π(a|s)

Return:
G_t = R_(t+1) + γR_(t+2) + γ²R_(t+3) + ...

Discount Factor:
0 ≤ γ ≤ 1


4. VALUE FUNCTIONS
------------------------------------------------------------

Vπ(s)

Aπ(s,a) = Qπ(s,a) - Vπ(s)

Optimal Value Function

V*(s)

Optimal Q Function

Q*(s,a)


5. BELLMAN EQUATIONS
------------------------------------------------------------
Bellman Expectation Equation

Vπ(s) =
Σ π(a|s) Σ P(s'|s,a)
[R(s,a,s') + γVπ(s')]

Bellman Optimality Equation

V*(s) =
max_a [R(s,a) + γΣP(s'|s,a)V*(s')]

Q*(s,a) =
R(s,a) + γΣP(s'|s,a) max_a' Q*(s',a')
