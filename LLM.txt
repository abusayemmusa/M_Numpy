========================================================
7. ATTENTION
========================================================

Attention is a core component of
Transformer-based LLMs.


Three components:

    Query (Q)
    Key (K)
    Value (V)


Formula:

    Attention(Q,K,V)
    =
    softmax(QKᵀ / √dₖ)V


Purpose:

    Determine which tokens are important
    to each other.

  └──── + <──────┘
         ↓

    Easier optimization


========================================================
15. CAUSAL LANGUAGE MODELING
========================================================

LLM predicts:

    Next Token


Example:

"The sky is"

Possible:

    "blue"


Process:

    Token 1
       ↓
    Token 2
       ↓
    Token 3
       ↓
    Predict next token


This is called:

    Autoregressive Generation


========================================================
16. NEXT-TOKEN PREDICTION
========================================================

Input:

    "Machine learning is"

Model predicts probability:

    useful → 0.30
    powerful → 0.25
    ...
    
Choose/sample next token.


Then:

    "Machine learning is powerful"

Predict next token again.


========================================================
17. CONTEXT WINDOW
========================================================

Context Window =
maximum amount of tokens a model can
process in one context.

Important concepts:

    Input Tokens
    Output Tokens
    Total Context
    Context Length


Longer context:

    More information can be processed.


========================================================
18. LOGITS
========================================================

Transformer
    ↓
Hidden States
    ↓
Linear Layer
    ↓
Logits
    ↓
Softmax
    ↓
Token Probabilities


Logits = unnormalized scores.


========================================================
19. SOFTMAX
========================================================

Converts logits into probabilities.

    logits
      ↓
    softmax
      ↓
 probabilities


Probability sum:

    1


========================================================
20. TEMPERATURE
========================================================

Temperature controls randomness.

Low temperature:

    More deterministic
    More predictable


High temperature:

    More diverse
    More random


Concept:

    Temperature ↑
        →
    randomness ↑


========================================================
21. TOP-K SAMPLING
========================================================

Select only the top K probable tokens.

Example:

    Top 5 tokens
        ↓
    Sample one


========================================================
22. TOP-P SAMPLING
========================================================

Also called:

    Nucleus Sampling

Select tokens until cumulative probability
reaches P.


Example:

    top_p = 0.9


========================================================
23. GREEDY DECODING
========================================================

Always select:

    Highest probability token


Simple but can produce repetitive output.


========================================================
24. BEAM SEARCH
========================================================

Maintain multiple candidate sequences.

Used in some:

    Translation
    Text generation
    Seq2Seq tasks

39. LoRA
========================================================

LoRA =
Low-Rank Adaptation


Instead of updating all model parameters:

    Freeze Base Model
          ↓
    Add Small Trainable Matrices
          ↓
    Train Adapters


Advantages:

    Lower memory
    Faster training
    Smaller checkpoints
